# playbridge

음악 앱이 다른 친구끼리 노래 목록을 링크 하나로 주고받는 웹앱입니다.
보내는 사람이 곡 목록을 만들면 링크가 생기고, 받는 사람은 자기 음악 앱을 골라 곡을 바로 열 수 있습니다.

## 화면

- **민트 카드 · 곡 목록**: 보내기 화면에서는 목록 이름과 곡 목록을 입력하고, 받은 노래 화면에서는 곡을 골라 엽니다.
- **테라코타 카드 · 앱 경로**: `친구의 앱 → 내 앱` 경로를 보여 주고, 받는 앱을 바꿀 수 있습니다.
- **레코드판 열기 버튼**: 곡을 고르면 판이 돌고(글자는 고정), 누르면 고른 앱의 검색 화면이 열립니다. 기기의 "동작 줄이기" 설정을 켜면 회전하지 않습니다.
- PC에서는 두 카드가 좌우로, 폰에서는 위아래로 배치됩니다.

## 사용 방법

1. `보내기`에서 한 줄에 한 곡씩 `가수 - 곡 제목` 형식으로 붙여넣습니다. (곡 제목만 적어도 됩니다.)
2. 내가 쓰는 앱을 고르고 `목록 만들기`를 누릅니다.
3. `링크 복사`로 친구에게 보냅니다.
4. 받는 사람은 링크를 열고 자기 음악 앱을 고른 뒤 곡을 누릅니다. 고른 앱은 브라우저에 기억됩니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 화면 구조 |
| `style.css` | 디자인 |
| `app.js` | 동작(목록 만들기, 링크 읽기, 앱 고르기) |
| `favicon.svg` | 탭 아이콘 |
| `vercel.json` | 보안 헤더 설정 |

빌드 과정이 없는 정적 사이트입니다.

## 배포 (Vercel)

1. 이 폴더의 파일을 GitHub 저장소 최상단에 올립니다.
2. Vercel에서 `Add New → Project`로 저장소를 가져옵니다.
3. Framework Preset은 `Other`, Build Command와 Output Directory는 비워 둡니다.
4. `Deploy`를 누릅니다.

## 보안 설계

- **서버에 목록을 저장하지 않음**: 목록은 링크의 `#` 뒷부분에만 담깁니다. 이 부분은 서버로 전송되지 않습니다.
- **링크 데이터 검증**: 링크에서 읽은 값은 형식을 검사하고, 곡 200개·가수 100자·제목 150자·목록 이름 60자로 제한합니다. 잘못된 값은 버립니다.
- **XSS 방지**: 화면에 넣는 모든 글자는 이스케이프합니다.
- **링크 주소 고정**: 곡 링크는 정해진 앱별 https 주소 틀에 검색어만 인코딩해서 넣습니다.
- **보안 헤더(`vercel.json`)**: 같은 출처의 스크립트·스타일만 허용하는 CSP, 다른 사이트 안에 넣어 보여 주기 차단, MIME 추측 차단, 리퍼러 미전송, 카메라·마이크·위치 권한 차단.
- **로그인 정보 미수집**: 음악 앱 아이디·비밀번호를 받지 않습니다.

## 한계

- 곡을 열면 각 앱의 **검색 화면**으로 이동합니다. 자동 재생이나 보관함 담기는 하지 않습니다.
- 앱별 검색 주소가 폰·카카오톡에서 어떻게 열리는지는 실제 기기에서 확인이 필요합니다.
- 곡이 많으면 링크가 길어집니다. 목록을 나누도록 안내합니다.
- `캡처로 넣기`는 다음 버전에서 추가할 예정입니다.
